## Tips

- **Customize shortcuts**: Open Keyboard Shortcuts (`Ctrl + K Ctrl + S`) and search for any command to assign a custom shortcut.
- **Keybinding conflicts**: If a shortcut isn't working, another extension or application might be using it.
- **Keybinding JSON**: For advanced customization, edit `keybindings.json` directly from the Keyboard Shortcuts editor.
